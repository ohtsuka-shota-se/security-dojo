# セキュリティ道場 — SEC//DOJO

LPIC-1 102（Topic 110 セキュリティ）の実習用シミュレータです。ブラウザだけで、
2台の仮想マシン（srv / pc）を相手に、権限管理・パスワード・特殊権限の監査・
サービス制御・SSH・GnuPG を手を動かして学べます。単一HTMLで動作し、
サーバーもビルドも不要です。

**公開ページ**: https://ohtsuka-shota-se.github.io/security-dojo/

## 収録内容（6ステージ / 全30ミッション）

1. 管理者権限（110.1） — id・sudo -l、su / su -、visudo、最小権限
2. パスワードとアカウント（110.1/110.2） — shadow 9欄、chage、ロック、/etc/nologin
3. 監査する（110.1） — SUID/SGID と find -perm、スティッキー、ss/lsof、不要サービス停止
4. ホストを守る（110.2） — sshd -T で実効設定を読み、安全側に設定
5. SSH（110.3） — 鍵の作成・登録・権限、ssh-agent、TCP Wrappers、ポート転送
6. GnuPG（110.3） — 鍵の生成・交換、暗号化と復号、署名と検証、失効

進捗はブラウザの localStorage に保存されます。何を打っても実機には影響しません。
想定環境は Ubuntu 24.04（OpenSSH 9.6 / GnuPG 2.4 / sudo 1.9）。

## ローカルで開く

`index.html` をブラウザで開くだけです（ダブルクリック可）。
