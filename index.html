セキュリティ道場

LPIC-1 102（Topic 110）の実習用シミュレータです。2台の仮想マシンを相手に、権限管理（su・sudo・visudo）、パスワードと期限（shadow・chage）、特殊権限の監査（SUID・find）、サービスとアクセス制御、SSH 鍵認証とトンネル、GnuPG の暗号化と署名を、手を動かして学びます。何を打っても本物のマシンには影響しません。

📘 この道場って何？（はじめての方はここから）

Linux サーバーを「安全に保つ」ための基本動作を、実際のコマンドで体験します。練習用に、2台の仮想マシンが用意されています。

srv 192.168.10.20社内サーバー。SSH・Web(nginx)・FTP が動いている。社内LAN(10.0.0.0/24)にもつながっている唯一のマシン。
pc 192.168.10.55あなたの手元の PC。ステージ5以降（SSH）では、ここから srv に接続します。

ユーザーは tanaka（あなた。sudo 権限あり）と sato（一般ユーザー。パスワード sato123）。tanaka の sudo パスワードは、練習機では何を入れても通ります。

  • ステージ1 管理者権限：id・sudo -l、su と su -、visudo、最小権限
  • ステージ2 パスワードとアカウント：shadow の9欄、chage、ロック、/etc/nologin
  • ステージ3 監査する：SUID/SGID と find -perm、スティッキー、ss/lsof、要らないサービスの停止
  • ステージ4 ホストを守る：sshd -T で実効設定を読み、安全側に設定する
  • ステージ5 SSH：鍵の作成・登録、パーミッション、ssh-agent、TCP Wrappers、ポート転送
  • ステージ6 GnuPG：鍵の生成・交換、暗号化と復号、署名と検証、失効

使い方：①左のミッションを読む → ②右の黒い画面をクリックしてキーボードで入力 → ③ミッション内のチェックが全部 ✓ になればクリア。右下の現在の状態は、操作に合わせて変わります。分からない言葉は 「📖 用語メモ」、詰まったら 「ヒント」を開いてください。日本語入力（IME）はオフにして操作します。

    権限の昇格

    sudo コマンド
    許可された範囲で root 実行（-l 権限一覧 / -i ログインシェル / -u ユーザー指定）
    su - [ユーザー]
    ログインシェルで切替（環境を初期化）。su は環境を引き継ぐ
    visudo [-c -f]
    sudoers を安全に編集（-c 検査 / -f 別ファイル）。/etc/sudoers.d/ 推奨
    id / whoami
    自分の UID・所属グループ

    パスワード・アカウント

    chage -l / -m -M -W -I -E -d
    期限管理。-d 0 で次回変更を強制。-E 失効日
    passwd -l / -u / -S / -e
    ロック / 解除 / 状態表示 / 失効
    usermod -L / -U / -e
    ロック / 解除 / 失効日（大文字に注意）
    /etc/shadow
    9欄：名:ハッシュ:最終変更:最短:最長:警告:猶予:失効:予約。$y$ yescrypt / $6$ SHA-512
    /etc/nologin, issue, motd
    root 以外拒否 / ログイン前 / ログイン後の表示

    特殊権限と監査

    find / -perm -4000 -type f
    SUID が立っている（AND）ファイル。/6000 は SUID か SGID（OR）
    SUID 4000 / SGID 2000 / Sticky 1000
    所有者権限で実行 / グループ権限 / 消せるのは持ち主だけ(/tmp)
    chmod u+s / g+s / +t
    特殊権限の付与。ls で s / s / t と表示
    ss -tulnp / lsof -i :80 / fuser -k
    待受ポート / ポートを掴むプロセス / 強制終了
    who / w / last / lastb
    ログイン中 / 詳細 / ログイン履歴 / 失敗履歴
    ulimit -u / -n / -H / -S
    最大プロセス / FD / ハード・ソフト。恒久は limits.conf

    サービス（systemd）

    systemctl status / start / stop
    状態 / 起動 / 停止
    systemctl enable / disable [--now]
    自動起動 ON / OFF（--now で即時も）
    systemctl mask
    起動そのものを禁止（巻き添え起動も防ぐ）
    journalctl -u sshd
    サービスのログ（旧：/var/log/auth.log, secure）

    SSH（110.3）

    ssh-keygen -t ed25519 [-b] [-f]
    鍵ペア作成。-l 指紋 / -R ホスト削除
    ssh-copy-id user@host
    公開鍵を相手の authorized_keys に登録
    秘密鍵 600 / ~/.ssh 700
    緩いと ssh が鍵を無視（StrictModes）
    eval $(ssh-agent) → ssh-add
    パスフレーズをメモリに預ける（-l 一覧 / -D 全削除）
    ssh -L l:host:r / -R / -D
    ローカル / リモート / 動的(SOCKS) ポート転送。-X は X11
    sshd -t / sshd -T
    文法検査 / 実効設定の表示。設定は sshd_config(.d)

    アクセス制御・暗号

    hosts.allow → hosts.deny
    TCP Wrappers。allow 優先。末尾ドット・EXCEPT・PARANOID
    ldd $(which sshd) | grep libwrap
    その sshd が Wrappers 対応か確認
    gpg --gen-key / -k / -K
    鍵生成 / 公開鍵一覧 / 秘密鍵一覧
    gpg --export -a / --import
    テキストで書き出し / 取り込み
    gpg -e -r 相手 / -d / -c
    公開鍵で暗号化 / 復号 / 共通鍵（パスフレーズ）
    gpg --clearsign / -b / --verify
    署名 / 分離署名 / 検証。--gen-revoke で失効証明書
